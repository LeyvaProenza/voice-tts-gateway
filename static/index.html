Especificaciones de API para Automatización (Antigravity)

Puedes generar audios automáticamente desde scripts de PowerPoint, videos o software educativo llamando a este endpoint local:

POST http://localhost:8000/api/tts 
{
  "text": "Bienvenidos a la unidad didáctica sobre metodología.",
  "voice": "es-MX-JorgeNeural",
  "speed": 0.95
}
{
  "text": "Welcome to this introductory lesson on science.",
  "voice": "af_heart",
  "speed": 0.95
}

Respuesta: El endpoint devuelve el archivo audio/wav binario directamente con código HTTP 200, listo para ser insertado en diapositivas o reproducido.
