API para Antigravity

Antigravity puede enviar texto a este endpoint y recibir audio WAV directamente.

POST http://localhost:8000/api/tts 
{
  "text": "Texto a sintetizar",
  "speaker_wav": "mi_voz.wav",
  "language": "es"
}

Se aplican automáticamente si no los incluyes en la petición:

{
  "temperature": 0.75,
  "length_penalty": 1.0,
  "repetition_penalty": 5.0,
  "top_k": 50,
  "top_p": 0.85
}

audio/wav — Bytes del audio WAV directamente. Guardar como archivo .wav.

Ajustes Avanzados de Voz (Opcionales)
Mayor = más expresiva/inestable. Menor = más monótona/estable.
Mayor = habla más lento/pausado. Menor = habla más rápido.
Evita que la voz repita sílabas o se trabe en bucles.
Filtra la diversidad de tonos (menor = más predecible/estable).
Delimita fonemas (mantiene el sonido natural).
